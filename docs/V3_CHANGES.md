# Targeted v3 closure record

This revision addresses the nine requested changes without changing the six-contract trust boundary. The tests below exercise local Direct Mode or application paths; Studio Dev consensus, fees and appeal execution still require a funded deployment.

| Change | Implementation | Specific verification |
| --- | --- | --- |
| Deterministic interval bounds | EventRegistry derives `intervalStartMin` and `intervalEndMax` from accepted lead/duration, reported start and evidence close. Validator and ObligationEngine reject an interval outside them. | `test_event_derives_accepted_window_interval_and_sources`; out-of-range leader mutations in `test_consensus_substantive_validator_and_hostile_package`; effect gate. |
| Whole-manifest budgets | Each package is capped at 4 KiB / 10 facts, the manifest at 24 items / 128 KiB / 240 facts, and per-source slots reserve capacity for linked parties and accepted external sources. Retrieval budget exhaustion or unavailable evidence yields UNDETERMINED. | `budget` and `bytes_budget` Direct cases; admission-capacity tests and oversize Worker ingress. |
| Authorised external sources | Accepted policy lists registered external source IDs; EventRegistry freezes the union into the event, EvidenceRegistry and gateway check it. | `test_accepted_window_external_sources_and_policy_taxonomy`; `test_evidence_window_challenge_and_immutable_manifest`; authenticated gateway source denial. |
| Configurable accepted window | Policy version declares 10 to 10,080 minutes; counterparty accepts. Multi-agreement event takes the longest, preventing shorter linked agreements from closing another party's window. The 10-minute minimum supports short Studio Dev iteration, 10-minute live runs have completed all three evidence commits; a 5-minute window is a reasonable next iteration when packages and signers are pre-staged. | Policy and event Direct tests above, early closure test. |
| OBSERVE and ENFORCE | OBSERVE stores measurements without beneficiary, obligor or claimable credit. ENFORCE records a DUE obligation; positive service credits can be claimed by the beneficiary signer once. No payment transfer is represented. | `test_multi_policy_effects_and_undetermined_gate`, including wrong signer, OBSERVE claim and duplicate claim. |
| Industrial cause taxonomy | Accepted version bounds causes using maintenance, planned work, process, controls, instrumentation, utility, feedstock, OEM, third-party and force majeure codes. Validator rejects causes outside linked policies. | Policy taxonomy test and wrong-cause validator attacks. |
| App Router | `/`, `/events`, `/events/[eventId]`, `/assets`, `/agreements`, `/evidence`, `/determinations`, `/effects`, `/organisations` and `/audit` render actual workspace pages. Navigation, event register and appeal are separate components. | `nine-changes.test.mjs` route mapping, browser smoke and configured route navigation smoke. |
| Event appeals | Worker verifies decoded consensus recipient, method and event for tracked transaction history, including ACCEPTED. Actual appeal remains unverified after live validator disagreement. |
| Worst-case fee profiles | Simulation and finalized receipt measurements aggregate maximum allocations independently per method; `measure` requires two distinct named scenarios for each expensive method. | `nine-changes.test.mjs` checks cross-dimensional maxima and representative coverage rejection.
